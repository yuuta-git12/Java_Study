# Javaの反復構造
## while文
- while文は条件式がtrueの間、処理を繰り返す構造です。
- while文の構文は以下の通りです。
```java
while (条件式) {
    // 条件式がtrueの間、繰り返す処理
}
```
- 条件式がfalseになると、while文の処理は終了します。
- 例として、1から5までの数字を出力するwhile文を示します。
```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```
- 条件式の中で変数宣言を行うことはできません。変数はwhile文の外で宣言する必要があります。
### コンパイルエラーになる例
```java
// ブロックの処理に入ることができないため、コンパイルエラーになります。
while(!true) {
    System.out.println("Hello");
}

// ブロックの処理に入ることができないため、コンパイルエラーになります。
while(1 == 2){
    System.out.println("Hello");    
}
```


## do-while文
- do-while文は、少なくとも1回は処理を実行し、その後条件式を評価して処理を繰り返す構造です。
- do-while文の構文は以下の通りです。
```java
do {
    // 繰り返す処理
} while (条件式);
```
- 条件式がfalseになると、do-while文の処理は終了します。
- 例として、1から5までの数字を出力するdo-while文を示します。
```java
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
```

## for文
- for文は、繰り返し処理を行うための構造です。初期化、条件式、更新処理を1行で記述できるため、while文やdo-while文よりも簡潔に書くことができます。
- for文の構文は以下の通りです。
```java
for (初期化; 条件式; 更新処理) {
    // 繰り返す処理
}
```
- 例として、1から5までの数字を出力するfor文を示します。
```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```
- for文の初期化、条件式、更新処理は省略することもできますが、省略した場合は無限ループになる可能性があるため注意が必要です。
- また、for文の中で変数宣言を行うことができます。**変数はfor文のスコープ内でのみ有効です。**
- 例として、for文の中で変数を宣言する場合を示します。
```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
// iはfor文のスコープ外では使用できません。
```
## 拡張for文（for-each文）
- 拡張for文は、配列やコレクションの要素を順番に処理するための構造です。配列やコレクションの要素数を意識せずに、簡潔に書くことができます。
- 拡張for文の構文は以下の通りです。
```java
for (データ型 変数名 : 配列やコレクション) {
    // 繰り返す処理
}
```
- 例として、配列の要素を順番に出力する拡張for文を示します。
```java
int[] numbers = {1, 2, 3, 4, 5};
for (int number : numbers) {
    System.out.println(number);
}
```
- 拡張for文では、配列やコレクションの要素を直接操作することはできません。要素の値を変更したい場合は、通常のfor文を使用する必要があります。
- 例として、配列の要素を変更する場合を示します。
```java
int[] numbers = {1, 2, 3, 4, 5};
for (int i = 0; i < numbers.length; i++) {
    numbers[i] = numbers[i] * 2; // 要素の値を変更
}
for (int number : numbers) {
    System.out.println(number); // 変更後の値を出力
}
```
- 例として、拡張for文で配列の要素を変更しようとする場合を示します。
- 以下の場合は、拡張for文の変数`fruit`は配列の要素を参照しているわけではなく、単なるコピーであるため、元の配列の要素は変更されません。したがって、出力されるのは変更後の文字列ではなく、元の文字列に「:果物」を付加した新しい文字列です。
```java
String[] fruits = {"Apple","Banana","Cherry"};
for(String fruit : fruits){
    fruit = fruit + ":果物";
    System.out.println(fruit);
}
```
## break,continue文
- break文は、ループ処理を途中で終了させるための構造です。ループ内でbreak文が実行されると、ループを抜けて次の処理に移ります。
- 例として、1から10までの数字を出力するループで、5に達したらループを終了する場合を示します。
```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break; // ループを終了
    }
    System.out.println(i);
}
```
- continue文は、ループ処理の現在の反復をスキップして、次の反復に移るための構造です。ループ内でcontinue文が実行されると、現在の反復の残りの処理をスキップして、次の反復に移ります。
- 例として、1から10までの数字を出力するループで、偶数の数字をスキップする場合を示します。
```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // 偶数の場合はスキップ
    }
    System.out.println(i);
}
```
### ラベルによるbreak,continue文
- break文やcontinue文は、ループの中で使用されることが多いですが、ネストされたループの中で特定のループを終了させたい場合や、特定のループの次の反復に移りたい場合があります。そのような場合には、ラベルを使用することができます。
- ラベルは、ループの前に任意の名前を付けることで、特定のループを識別するために使用されます。ラベルを使用することで、ネストされたループの中で特定のループを終了させたり、次の反復に移ることができます。
- ラベルの構文は以下の通りです。
```java
ラベル名: for (初期化; 条件式; 更新処理) {
    // 繰り返す処理
}
```
- 例として、ラベルを使用してネストされたループの中で特定のループを終了させる場合を示します。
```java
outerLoop: for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) {
            break outerLoop; // outerLoopラベルのループを終了
        }
        System.out.println("i: " + i + ", j: " + j);
    }
}
```
