## オーバーライドとは?
- オーバーライドとは、スーパークラス（親クラス）で定義されたメソッドをサブクラス（子クラス）で再定義すること
- これにより、サブクラスはスーパークラスのメソッドの振る舞いを変更することができる
## オーバーライドの条件
- シグネチャが同じであること
  - メソッド名が同じであること
  - 引数の型と数が同じであること
- 戻り値の型
  - 同じ型
  - スーパークラスの戻り値の方のサブクラスであること（共変戻り値型）
- アクセス修飾子
  - スーパークラスのアクセス修飾子と同じか、より広いアクセス修飾子であること
  - 例：
    - スーパークラスのメソッドが `protected` の場合、サブクラスのメソッドは `protected` または `public` である必要がある
    - スーパークラスのメソッドが `public` の場合、サブクラスのメソッドも `public` である必要がある
    - スーパークラスのメソッドが `public` の場合、サブクラスのメソッドを `protected` にすることはできない
