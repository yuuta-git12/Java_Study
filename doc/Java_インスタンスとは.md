# インスタンスとは

- インスタンス＝メモリ上に実際に作られたオブジェクトの実体のこと 
- 変数はそのインスタンスへの「参照(住所)」を持っているだけ

```java
String a = new String("hello");
String b = new String("hello");

System.out.println(a == b); // false（参照先が違う＝別インスタンス）
```
- aとbは同じStringクラスですが、newで2回作っている.
- メモリ上には別々の実体が存在します。中身（文字列）は同じでも「モノ」としては別です。
- 「インスタンスが違う」の意味は基本的に「メモリ上の別々のオブジェクトを指している」ということで、これはクラスが同じでも違っても起こります。

- インスタンスを代入する変数は、型を明示する代わりに`var`を使って型推論させても良い(型を持つのはあくまで変数であり、`var`自体は型ではなくコンパイラに型推論させるためのキーワード)
```java
var c = new String("hello"); // String型と推論される
```
