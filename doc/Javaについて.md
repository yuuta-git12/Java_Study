# Javaについて

## Java環境（JVM・JRE・JDK）
- JVM
  - Javaプログラムを動かすもの
  - Javaのコードをコンパイルしバイトコードにしたものを動かす
- JRE
  - ライブラリやJVMを含んだもの
- JDK
  - JREを含んだ開発に必要な環境

## Javaプログラム実行までの流れ
1. プログラム作成
2. コンパイル
   1. コンパイルエラーがあればエラーメッセージを確認し修正
   2. `javac`コマンドでコンパイルする
3. 実行
   1. `java クラス名`コマンドで実行する
4. デバッグ
   1. 実行時の実行時エラーや実行時例外、バグを取り除く
5. 2に戻って再度コンパイル

### ソースファイルモード
- コンパイルなしでJavaプログラムを実行できる
- 実行するには3つの条件がある
  - 1. ソースファイルが1つであること
  - 2. 実行するクラス（mainメソッドを持つクラス）がファイルの先頭に宣言されていること
  - 3. 外部のクラスファイル（.class）を使用しないこと

## プログラムについて
- Javaはクラス単位でファイルを作成する
- １つのファイルには複数のクラスを宣言することが可能
  - ただし、１ファイルに複数クラスを宣言するとどのファイルに何のクラスが宣言されているか分かりにくいので、**1ファイル1クラス宣言が基本**
- `public`がついたクラスは**１つのソースファイルに1クラスしか宣言できない**

### 実行時に呼ばれるメソッド
- 実行時に呼ばれるメソッドは以下の書き方をしているメソッド
```java
public static void main(String[] args){}

public static void main(String... s){}

public static void main(String args[]){}
```

## パッケージ宣言
- パッケージの目的は**クラスファイルを管理すること**
- 無名パッケージ：パッケージ宣言のないクラス
### パッケージ名の慣習
- クラス名の衝突防止のため、ドメイン名を逆に指定する
- `package jp.co.sample;`
### パッケージ化したクラスの実行方法
- 完全修飾名で呼び出す必要がある
- パッケージ宣言と同じディレクトリ構造を作成し、そこにJavaファイルを保存する
### パッケージ化されたクラスのコンパイルと実行
- 以下のコマンドでディレクトリを指定してコンパイルが必要
- `javac -d <パッケージを生成するディレクトリ> <コンパイル対象のソースファイル名>`
### クラスパス
- クラスを検索するためのパス
- `-cp`,`-classpath`オプションを使用する

## インポート
- 他のクラスを使用したい場合に必要な宣言
- `import 完全修飾名`
- パッケージ宣言がある場合はその下に記述する

## Java標準のAPIパッケージ
- Javaに標準で組み込まれている標準APIはインポート宣言を行わなくてもクラス名のみで使用できる
- 標準APIはJavaの公式ドキュメントにまとめられている
