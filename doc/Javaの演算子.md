# Javaの演算子
## 前置演算子と後置演算子の違い
- **前置演算子**（`++i`, `--i`）: 変数の値を先にインクリメント/デクリメントしてから式の中で使用する。
- **後置演算子**（`i++`, `i--`）: 式の中で変数の現在の値を使用してから、インクリメント/デクリメントする。
```java
int i = 5;
System.out.println(++i); // 出力: 6（先にインクリメントしてから出力）
System.out.println(i++); // 出力: 6（出力してからインクリメント）
System.out.println(i);   // 出力: 7
```

## 関係演算子
- 2つの値を比較し、`boolean`型（`true` / `false`）を返す演算子。

| 演算子 | 意味 |
|:---:|:---|
| `==` | 等しい |
| `!=` | 等しくない |
| `<` | 左辺が右辺より小さい |
| `>` | 左辺が右辺より大きい |
| `<=` | 左辺が右辺以下 |
| `>=` | 左辺が右辺以上 |

```java
int a = 5;
int b = 10;
System.out.println(a == b); // false
System.out.println(a < b);  // true
System.out.println(a != b); // true
```

## 論理演算子
- `boolean`型の値を組み合わせて評価する演算子。

| 演算子 | 意味 |
|:---:|:---|
| `&&` | 論理積（AND）：両辺がtrueのときtrue（短絡評価あり） |
| `\|\|` | 論理和（OR）：どちらか一方がtrueのときtrue（短絡評価あり） |
| `!` | 否定（NOT）：trueをfalse、falseをtrueに反転 |
| `&` | 論理積（AND）：短絡評価なし |
| `\|` | 論理和（OR）：短絡評価なし |

### &&と&の違い
- &&は短絡評価を行う論理積演算子であり、左辺がfalseの場合、右辺の評価を行わない。
- &は論理積演算子であり、左辺がfalseでも右辺の評価を行う。
```java
int a = 5;
int b = 10;
boolean result = (a < b) && (b > 5); // 短絡評価が行われる
// a < bがtrueなので、右辺の評価も行われる

boolean result = (a > b) && (b > 5); // 短絡評価が行われる
// a > bがfalseなので、右辺の評価は行われない
```
### ||と|の違い
- ||は短絡評価を行う論理和演算子であり、左辺がtrueの場合、右辺の評価を行わない。
- |は論理和演算子であり、左辺がtrueでも右辺の評価を行う。
```java
int a = 5;
int b = 10;
boolean result = (a < b) || (b > 5); // 短絡評価が行われる
// a < bがtrueなので、右辺の評価は行われない

boolean result = (a > b) || (b > 5); // 短絡評価が行われる
// a > bがfalseなので、右辺の評価が行われる
```

## 条件演算子(三項演算子)
- 条件演算子は、三項演算子とも呼ばれ、次のように使用されます。
```java
int a = 10;
int b = 20;
int max = (a > b) ? a : b; // aがbより大きい場合はaを、そうでない場合はbをmaxに代入する
```

## 基本データ型と参照型の比較
- 基本データ型は、変数に直接値を格納するのに対し、参照型は、変数にオブジェクトの参照（アドレス）を格納します。
- 基本データ型は、メモリ上に固定されたサイズの領域を持ち、参照型は、オブジェクトのサイズに応じて可変的にメモリを確保します。
- 基本データ型は、値のコピーを渡すため、値の変更は元の変数に影響を与えませんが、参照型は、オブジェクトの参照を渡すため、オブジェクトの内容を変更すると元の変数にも影響を与えます。
- 基本データ型は、プリミティブ型のため、比較演算子（==）で値の比較が可能ですが、参照型は、オブジェクトの参照を比較するため、比較演算子（==）で値の比較はできません。参照型の値を比較する場合は、equals()メソッドを使用する必要があります。
```java
short s = 10;
int i = 10;
System.out.println(s == i); // true

double d = 10.0;
float f = 10.0f;
System.out.println(d == f); // true

String str1 = new String("Hello");
String str2 = new String("Hello");
System.out.println(str1 == str2); // false
System.out.println(str1.equals(str2)); // true
```
### オブジェクトの同一性と等価性
- 同一性：
  - オブジェクトの同一性は、2つのオブジェクトが同じメモリ上のアドレスを持つかどうかを比較することです。
  - 同一性を比較するには、比較演算子（==）を使用します。
  - （例）同姓同名でも違う人なので、同一のオブジェクトではない
- 等価性：
  - オブジェクトの等価性は、2つのオブジェクトが同じ値を持つかどうかを比較することです。
  - 等価性を比較するには、equals()メソッドを使用します。
  - （例）同姓同名であれば、等価なオブジェクトとみなすことができる

### インターン化
- インターン化とは、同じ値を持つ文字列リテラルを1つのオブジェクトとして共有することです。
- 文字列リテラルは、Javaのコンパイル時に自動的にインターン化されます。
- 文字列リテラルを使用すると、同じ値を持つ文字列リテラルは、同じオブジェクトを参照するため、メモリの使用量を削減できます。
- 文字列リテラルを使用せずに、new演算子で文字列オブジェクトを生成すると、同じ値を持つ文字列でも異なるオブジェクトとして生成されるため、メモリの使用量が増加します。
```java
String str1 = "Hello";
String str2 = "Hello";
System.out.println(str1 == str2); // true
String str3 = new String("Hello");
System.out.println(str1 == str3); // false

String str4 = str3.intern();
System.out.println(str1 == str4); // true
```

## 基本データ型から参照型への変換

- 基本データ型から参照型への変換は、ボクシング（Boxing）と呼ばれます。Javaでは、基本データ型の値をラッパークラスのオブジェクトに変換することができます。ラッパークラスは、基本データ型に対応するクラスであり、以下のように対応しています。

| 基本データ型 | ラッパークラス |
|:---:|:---:|
| byte | Byte |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |
  - ボクシングは、基本データ型の値をラッパークラスのオブジェクトに変換することで、参照型として扱うことができます。
  - 例：
```java
int i = 10;
Integer integerObj = Integer.valueOf(i); // ボクシング
int j = integerObj.intValue(); // アンボクシング
```

### 文字列の変換
- 文字列を基本データ型に変換するには、ラッパークラスのparseXXX()メソッドを使用します。XXXは、変換したい基本データ型の名前です。
- 例：
```java
String str = "123";
int i = Integer.parseInt(str); // 文字列をint型に変換
String str2 = "3.14";
double d = Double.parseDouble(str2); // 文字列をdouble型に変換
```

## 実務での基本データ型と参照型の使い分け
- 基本データ型は、メモリの使用量が少なく、処理速度が速いため、数値計算やループ処理などのパフォーマンスが重要な場面で使用されます。
- 参照型は、オブジェクト指向プログラミングの特性を活かすことができるため、データ構造やコレクションなどの複雑なデータを扱う場面で使用されます。
  - ただし、Javaでは自動的にボクシングとアンボクシングが行われるため、基本データ型と参照型の間での変換が容易に行えます。
- `if文`や`switch文`などの条件分岐では、基本データ型を使用することが一般的です。
- 参照型は、オブジェクトの状態や振る舞いを表現するために使用されます。
```java
String name = "Alice";
int age = 30;
if (age >= 18) {
    System.out.println(name + "は成人です。");
} else {
    System.out.println(name + "は未成年です。");
}
```
