# 概要
- JavaSilver学習用のプロジェクト
- 簡易的な銀行口座管理システムをCLIで作る

## 銀行口座管理システム（CLI）
- Account（抽象クラス）→ SavingsAccount / CheckingAccount
- 残高不足時に InsufficientFundsException（checked例外）をスロー
- 引き出し上限を超えた場合の独自例外も作ると、try-catch-finallyやマルチキャッチの練習になる
- 複数口座をコレクションで管理し、拡張for文やStream基礎（Silverでも軽く触れる範囲）で合計残高を計算

## プロジェクトの進め方
- Claude Codeとのペアプログラミング形式で進める

## 設計
- 口座クラスの設計
  - Account(抽象クラス)
    - メンバ変数
      - accountNumber: 
        - 型：String
        - 用途：口座番号
      - balance: pro
        - 型：double
        - 用途：残高
    - メンバメソッド
      - deposit(amount: double): 
        - 型：void
        - 用途：入金処理
      - withdraw(amount: double): 
        - 型：void
        - 用途：出金処理
        - throws：InsufficientFundsException
      - getBalance(): 
        - 型：double
        - 用途：残高を取得
  - SavingsAccount(普通預金口座)
    - 利息計算メソッドを追加することも検討
  - CheckingAccount(当座預金口座)
    - 引き出し上限を設定することも検討
- 作成するファイルの構成
```
Main.java
Account.java
SavingsAccount.java
CheckingAccount.java
```
- パッケージ構成
```
com.bankmanagement
    ├── Main.java
    ├── Account.java
    ├── SavingsAccount.java
    └── CheckingAccount.java
```
